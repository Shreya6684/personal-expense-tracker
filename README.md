# Personal Expense Tracker

A simple, interactive command-line Python application to help users manage personal budgets, track daily spending, and query expense records by category.

## Features

- **Set Budget Limits:** Define a maximum spending limit to keep track of financial goals.
- **Log Expenses with Dates:** Record expenditure amounts, custom categories (e.g., Food, Travel, Shopping), and transaction dates.
- **Automated Budget Alerts:** Get notified immediately if cumulative spending exceeds your set budget limit.
- **View Expense History:** Display a numbered list of all recorded expenses.
- **Calculate Total Spending:** Instantly calculate total expenditure across all categories.
- **Category Search:** Filter and search through expenses by category (case-insensitive).

## Prerequisites

- Python 3.x installed on your system.

1. Clone or download this repository.
2. Open your terminal or command prompt.
3. Navigate to the project directory containing `PERSONALEXPENSETRACKER.py`.
